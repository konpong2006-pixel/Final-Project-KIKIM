## 1. สแกนสลิปหลายใบ (ข้อ 2)

| ปัญหา | วิธีแก้ |
|---|---|

## 7. ชุดฟีดแบ็ก UX (อีก 10 จุด)

| ก่อนแก้ / ปัญหา | สิ่งที่แก้และวิธีแก้ |
|---|---|
| AI แนะนำเวลาเริ่มที่ผ่านไปแล้ว | คำนวณจากเวลาปัจจุบัน เผื่ออย่างน้อย 1 นาที และตรวจเวลาซ้ำก่อนเลือกกับก่อนบันทึก |
| เปิดคำแนะนำทิ้งไว้จนหมดอายุ แต่ยังดูเหมือนใช้ได้ | แสดงข้อความว่าช่วงเวลาผ่านไปแล้ว พร้อมทางไปคำนวณคำแนะนำใหม่ |
| ข้อความบางหน้าบอกต้องยืนยันทุกครั้ง แต่บางหน้าบอกบันทึกอัตโนมัติ | ปรับคำอธิบายให้ตรงกันว่า ข้อมูลครบและผ่านการตรวจจึงบันทึกอัตโนมัติ ส่วนที่ไม่ชัดหรืออาจซ้ำต้องตรวจ |
| รายการติดป้าย "มั่นใจสูง" แต่ยังรอตรวจ ทำให้สับสน | เปลี่ยนเป็น "อ่านข้อมูลมั่นใจสูง" และแสดงข้อควรตรวจ เพื่อแยกคะแนนการอ่านจากสถานะพร้อมบันทึก |
| ชื่อฟีเจอร์ระบุเฉพาะ LINE ทั้งที่รองรับแจ้งเตือนธนาคารด้วย | เปลี่ยนเป็น "อ่านแจ้งเตือนการเงิน" พร้อมปรับคำอธิบายและข้อความยินยอมให้ครอบคลุม LINE และแอปธนาคารที่รองรับ |
| ตอนยืนยันรายการระบุที่มาเป็น LINE ทั้งหมด | ส่งที่มาเดิมของรายการ และแสดงว่าเป็น LINE หรือแอปธนาคารในหน้ารอตรวจ |
| เลือกเดือนแล้วรีเฟรชกลับเป็นวัน | เก็บช่วงวัน/สัปดาห์/เดือน วันที่อ้างอิง และตัวกรองรายรับ–รายจ่ายไว้ใน URL |
| ตอนบ่ายยังทัก "สวัสดีตอนเช้า" | เปลี่ยนคำทักทายตามเวลาไทย และอัปเดตเมื่อเวลาเปลี่ยนหรือกลับเข้าแอป |
| มีคำว่า "ตอนตอนนี้" | แก้เป็น "ตอนนี้" |
| เว็บขึ้นคำเตือนจากระบบ native push | ป้องกันไม่ให้เว็บโหลดโมดูลแจ้งเตือนสำหรับ native โดยยังคงการโหลดบน Android |

**ตรวจแล้ว: ทำครบทั้ง 10 ข้อ** — เช็คจากโค้ดจริงในบรานช์นี้ (ไม่ใช่แค่อ่านเอกสาร) ทุกจุดมีอยู่จริงและอยู่ใน commit `cd6a149` แล้ว:

- `src/lib/ux-time.ts` — ฟังก์ชัน `bangkokGreeting()` (คำทักทายตามเวลาไทย) และ `futureSuggestion()` (เช็คคำแนะนำหมดอายุ)
- `src/screens/native/user/activity-form-screen.tsx` — เรียก `futureSuggestion()` ทั้งตอนเลือกคำแนะนำและก่อนบันทึก
- `src/screens/native/user/line-import-screen.tsx` — มีข้อความ "อ่านข้อมูลมั่นใจสูง" และส่ง `item.source` จริงเข้า `confirmLineTransaction` (ไม่ยัด LINE ให้ทุกรายการ)
- `src/screens/native/user/profile-screen.tsx`, `line-bank-screen.tsx`, `finance-screen.tsx` — เปลี่ยนชื่อฟีเจอร์เป็น "อ่านแจ้งเตือนการเงิน" แล้ว
- `src/screens/native/user/finance-screen.tsx` — ใช้ `useLocalSearchParams` เก็บช่วงวัน/ตัวกรองไว้ใน URL
