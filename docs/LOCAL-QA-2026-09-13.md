## จุดที่ต้องทำต่อ

แท็บทดสอบยังอยู่หน้า login ไม่มีเซสชันผู้ใช้ จึงต้องให้ผู้ใช้ล็อกอินเองเพื่อทดสอบ UI ต่อ ห้ามขอรหัสผ่านหรืออ่านข้อมูลรับรองมาใช้เอง

localhost เป็นเพียงตำแหน่งหน้าเว็บ โค้ด src/lib/firebase.ts ต่อ emulator เฉพาะเมื่อเปิด EXPO_PUBLIC_FIREBASE_EMULATOR เท่านั้น อย่าถือว่าเป็นฐานข้อมูลทดสอบโดยอัตโนมัติ การทดสอบบันทึกและ OCR ครบเส้นทางควรใช้ emulator/บัญชีทดสอบและ backend ที่ตรงชุด โดยตรวจผลข้างเคียงก่อน ไม่ deploy เพียงเพื่อให้ทดสอบผ่าน
