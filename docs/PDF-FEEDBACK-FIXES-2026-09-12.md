## คำสั่งตรวจสอบในเครื่อง

```cmd
npm run typecheck
npm --prefix functions run build
node --experimental-strip-types scripts/test-pdf-feedback.mjs
npm test
npm run build:web
```

ชุดทดสอบใหม่ครอบคลุมการคงชื่อ/ID งานเดิม, วันไกล, พ.ศ., timezone, วันและเวลาไม่ถูกต้อง, คำสั่งกำกวม, กำหนดส่ง, ไม่แก้งานที่ยืนยันแล้ว, รูปซ้ำ, reference ซ้ำ และไม่รวมการซื้อคนละใบที่ยอด/เวลาตรงกัน

## ข้อจำกัดและการตรวจรับก่อนใช้งานจริง

ผลตรวจในเครื่อง: TypeScript ผ่าน, Functions build ผ่าน, ชุดทดสอบหลัก `npm test` ผ่าน, ชุด regression ใหม่ผ่าน และ export เว็บผ่านพร้อมตรวจค่า Firebase ใน bundle ครบ ทั้งหมดนี้ไม่ใช่ผลทดสอบใช้งานบนโทรศัพท์จริง

- นี่เป็นผลแก้โค้ดในเครื่อง ยังไม่ใช่ยืนยันผลใช้งานบนโทรศัพท์หรือ production
- การป้องกันซ้ำไม่ได้ย้อนลบยอดซ้ำเก่า และรูปที่ครอป/แก้ไขจน hash เปลี่ยนและไม่มีเลขอ้างอิง อาจยังต้องตรวจเอง
- การแก้เวลาในแชตชุดนี้แก้ร่างที่ยังไม่บันทึก ไม่ใช่ย้ายกิจกรรมที่บันทึกแล้ว
- ต้องทดสอบบน Android และเว็บมือถือจริง: เลือกหลายรูป, ยกเลิก picker, OCR ล้มเหลวกลางคิว, กดบันทึกซ้ำ, สแกนรูปเดิมอีกครั้ง, ยอดสุทธิติดลบ, เข้า Finance วัน/สัปดาห์, รอ AI, แก้วันไกลและพับการ์ด, ข้อความแก้กำกวม
- ก่อนเผยแพร่ต้องประสานเพื่อนและตรวจ commit ล่าสุดอีกครั้ง รวมโค้ดที่ผ่านทดสอบบนฐานล่าสุด แล้ว deploy Functions (รวม `analyzeScan`, `saveReviewedReceipt`, `createAdaptiveActivity`) และ Hosting ให้ตรงชุด พร้อมกฎ Firestore ที่เกี่ยวข้อง อย่า deploy จาก checkout เก่า หรือเผยแพร่เว็บเพียงส่วนเดียว
