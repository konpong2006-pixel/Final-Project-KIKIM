## วิธีและข้อจำกัด

อ่านข้อมูลและสลับหน้าเป็นหลัก ไม่เพิ่ม/แก้/ลบรายการ ไม่ยืนยันรายการรอตรวจ ไม่บันทึกการนอน ไม่ส่ง feedback ไม่อัปโหลดไฟล์ ไม่สั่ง AI วิเคราะห์ใหม่ และไม่เชื่อม/ซิงก์ Google Calendar ไม่มี deploy/push

เวลารอบเครื่องมือไม่ใช่เวลาโหลดเว็บล้วน จึงไม่ใช้เป็น benchmark: สลับ Finance วัน/สัปดาห์/เดือนเห็นผลในรอบตรวจประมาณ 1–2 วินาที ส่วน Profile และ Notifications มีช่วง loading ก่อนแสดงผลในการตรวจถัดไป ไม่พบการค้างถาวรในรอบนี้ แต่ไม่ได้จับเวลาครบด้วย network instrumentation

## สิ่งที่ผ่านในขอบเขตนี้

- เซสชันเดิมพาเข้าหน้าผู้ใช้ได้โดยไม่ต้องกรอกรหัสผ่าน
- Dashboard และ Calendar แสดงกิจกรรมวันนี้ตรงกัน 2 รายการ และเวลาเริ่มตรงกัน
- งบวันนี้ Dashboard/Finance ตรงกัน 176 บาท; Finance แสดงงบเหลือ 3,000 บาท/17 วัน ซึ่งสอดคล้องกับการแสดงจำนวนเต็ม 176 (ไม่ยืนยันสูตร rounding จาก UI อย่างเดียว)
- Finance วัน/สัปดาห์/เดือนปรับหัวข้อและช่วงวันที่ถูกต้องเมื่อกด; ช่วงที่ตรวจมีรายรับรายจ่ายศูนย์ จึงยังทดสอบความถูกต้องเมื่อมีรายการจริง/ติดลบไม่ได้
- Profile โหลดสำเร็จ; จำนวนนับโน้ตตรงกับหน้า Notes ค่าอ้างอิงนอน 23:00–07:00 แสดง 8 ชั่วโมง เปิด time picker แล้วยกเลิกโดยไม่บันทึก
- Notes ที่ viewport 390x844 แสดงฟอร์มค้นหา การ์ด เมนู และข้อความในภาพที่ตรวจโดยไม่พบแนวนอนล้น คืน viewport เดิมแล้ว ข้อความรองค่อนข้างเล็ก ยังไม่ใช่ตรวจ responsive ทุกหน้า
- Smart Scan เปิดจากไอคอนสแกนใน Finance ได้ ไปหน้า smartlife_scan_schedule และเห็นปุ่มเพิ่มเอกสาร ไม่ได้กดอัปโหลด
- Notifications โหลด empty state และตัวนับศูนย์สอดคล้องกัน
