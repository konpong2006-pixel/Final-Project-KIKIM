## 1. AI แนะนำเวลาในอดีต

- เดิมเลือกช่วงว่างที่ยังไม่จบ แต่เริ่มกิจกรรมจากต้นช่วงซึ่งผ่านไปแล้ว
- ตัดส่วนของช่วงว่างที่ผ่านไปแล้วออกก่อนคำนวณระยะเวลา เผื่อเวลาอย่างน้อยหนึ่งนาทีและใช้วัน/เวลาไทย
- cache ใช้เวลาเริ่ม–จบเป็นส่วนหนึ่งของคีย์และคัดคำแนะนำหมดอายุก่อนส่งกลับ รวมถึงกรณีบริการ AI ล้มเหลว
- การ์ดหน้าแรกไม่แสดงช่วงเวลาหมดอายุเป็นคำแนะนำที่ใช้ได้ แต่แจ้งให้เปิดหน้าคำแนะนำเพื่อคำนวณใหม่
- ตรวจอีกครั้งตอนเลือกคำแนะนำและก่อนบันทึกกิจกรรม รวมถึงหลังรอหน้าต่างยืนยันตารางชน
- ไม่ห้ามผู้ใช้บันทึกกิจกรรมย้อนหลังที่กรอกเองตามพฤติกรรมเดิม

ทดสอบ: เวลา 13:14 มีช่วงว่างตั้งแต่ 12:00 ต้องเริ่ม 13:15 ไม่ใช่ 12:00 หากเหลือช่องว่างไม่ถึงระยะเวลาที่ต้องใช้ ให้เลือกช่วงถัดไป

## 2. ข้อความการนำเข้ากับรายการรอตรวจ

- ใช้คำอธิบายเดียวกัน: ข้อมูลครบ มั่นใจสูง และผ่านการตรวจ จึงบันทึกอัตโนมัติ รายการไม่ชัดหรืออาจซ้ำยังต้องตรวจ
- เปลี่ยนป้ายเป็น “อ่านข้อมูลมั่นใจสูง” เพื่อไม่ให้เข้าใจว่าเท่ากับอนุมัติบันทึกแล้ว
- การ์ดแสดงข้อควรตรวจจาก warnings หรือข้อความให้ยืนยันข้อมูล โดยไม่เดาสาเหตุเฉพาะที่ระบบไม่ได้ส่งมา
- ไม่ลดเกณฑ์การบันทึกและไม่ลบระบบตรวจรายการซ้ำ

ทดสอบ: รายการคะแนนสูงแต่มีคำเตือนยังควรแสดงเหตุผลรอตรวจ ส่วนรายการบันทึกแล้วให้ดูหน้าการเงิน

## 3. จำช่วงการเงินหลังรีเฟรช

- เก็บวัน/สัปดาห์/เดือน วันที่อ้างอิง และตัวกรองรายรับ/รายจ่ายไว้ใน URL ด้วย Expo Router
- โหลดค่าจาก URL กลับมาเมื่อรีเฟรช พร้อมตรวจรูปแบบวันที่และใช้ค่าเริ่มต้นเมื่อไม่ถูกต้อง
- ปุ่มเลื่อนช่วงและเลือกตัวกรองเปลี่ยน URL ด้วย รองรับย้อนหลัง/ไปข้างหน้าผ่านประวัติเบราว์เซอร์
- นี่คือการจำค่าของหน้าที่เปิด ไม่ใช่การตั้งค่าถาวรทั้งบัญชีเมื่อกลับเข้าจากเมนูอื่น

ทดสอบด้วยบัญชีทดสอบ: เลือกเดือน เลื่อนเดือน เลือกรายจ่าย รีเฟรช แล้วตรวจว่าเดือนและตัวกรองเดิมยังอยู่ รวมถึงปุ่ม Back/Forward

## 4. คำทักทายและคำผิด

- คำทักทายคำนวณตามเวลาไทย: 00:00–04:59 ยามดึก, 05:00–11:59 เช้า, 12:00–16:59 บ่าย, 17:00–23:59 เย็น
- มีนาฬิกาอัปเดตทุก 15 วินาทีและเมื่อกลับเข้าแอป/โฟกัสเว็บ ไม่ค้างคำทักทายเดิมตลอดหน้า
- แก้ “ตอนตอนนี้” เป็น “ตอนนี้” ในหน้าการแจ้งเตือน

## 5. คำเตือน native push บนเว็บ

- พบว่า import expo-notifications เรียกลงทะเบียนตัวฟัง native push ระหว่างโหลดโมดูล
- โหลดโมดูลนี้เฉพาะแพลตฟอร์ม native และกันฟังก์ชันแจ้งเตือน/ยกเลิกการเตือนที่เกี่ยวข้องบนเว็บ
- ไม่ปิด console warnings ทั้งระบบ และไม่ได้เพิ่มระบบ Web Push ใหม่
- การแก้นี้ไม่ใช่หลักฐานว่าการแจ้งเตือนทุกชนิดหรือ Android background notifications ผ่านการทดสอบแล้ว

## 6. ชื่อฟีเจอร์ครอบคลุม LINE และแอปธนาคาร

- ใช้ชื่อ “อ่านแจ้งเตือนการเงิน” ในหน้าการเงิน โปรไฟล์ หน้านำเข้า และตั้งค่า
- อธิบายว่าอ่านจาก LINE และแอปธนาคารที่รองรับบน Android ไม่ใช่ดึงข้อมูลภายในบัญชีธนาคารหรือเปิดแชตย้อนหลัง
- ปรับข้อความยินยอม ความเป็นส่วนตัว และข้อความแจ้งเตือนให้ตรงกับการทำงาน ไม่สัญญาว่ารองรับทุกธนาคาร
- แสดงที่มา LINE/แอปธนาคารบนการ์ดรายการรอตรวจ
- แก้การยืนยันรายการให้ส่ง source เดิมของรายการ แทนการระบุทุกอันว่าเป็น LINE
