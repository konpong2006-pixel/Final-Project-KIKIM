## หมายเหตุ

- คู่ `07a` / `07b` คือหลักฐานว่า adaptive scheduling ส่งผลจริง: ข้อมูลและคำขอเหมือนกันทุกอย่าง
  ต่างกันแค่สวิตช์ "เรียนรู้จากพฤติกรรม" แล้วเวลาที่ระบบเสนอเปลี่ยนไปคนละช่วง
- ข้อมูลทดสอบที่ใช้สร้างภาพ `02`, `06`, `07a`, `07b` ถูกลบออกหลังถ่ายเสร็จแล้ว
  ภาพเหล่านี้จึงเป็นบันทึกของตอนนั้น ไม่ใช่สถานะปัจจุบันของบัญชี
- ไม่ได้อัปโหลดใบเสร็จจริงในขั้นตอน OCR เพื่อไม่ให้เปลืองโควตาเรียก API จริง (ภาพ `09`)
  ส่วนภาพ `21` อัปโหลดใบเสร็จจริงและยิง Cloud Vision OCR จริง จึงเห็นหมวดหมู่ที่ระบบแยกให้
- ภาพ `22` / `22b` ต้องทำให้เข้าเงื่อนไขเกินงบก่อน จึงลดวงเงินเดือนชั่วคราวจาก ฿5,600 เป็น ฿1,000
  ถ่ายภาพแล้วคืนค่ากลับเป็น ฿5,600 (โหมด AI แนะนำ) ทันที ยอดใช้จ่าย ฿1,109 เป็นข้อมูลจริงไม่ได้แต่งเติม
- ภาพ `18` และ `19` อยู่บนหน้า **ผู้ช่วย AI** ไม่ใช่หน้า Burnout Predictor แยกต่างหาก เพราะแอปไม่มีหน้านั้น
- คะแนนหมดไฟใน `18` (15/100 จากสูตรในเครื่อง) กับใน `19` (55/100 ที่ Gemini เขียนเอง) ยังไม่ตรงกัน
  ถ้าจะใช้ในสไลด์ควรเลือกภาพเดียว หรือระบุว่าเป็นคนละแหล่งคำนวณ
- `14` ยังมีชื่อผู้ใช้เป็นข้อความทดสอบ และ `17` มีอีเมลผู้ใช้ปรากฏบนการ์ดซิงก์
